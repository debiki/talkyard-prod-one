
Release Channels
======================================================================

You will be able to choose between
\1) getting new features and bug fixes more often — the 'regular' releae branch.
Or 2) getting only important bug fixes — the 'stable' branch.

You choose this, by editing `/opt/talkyard-v1/.env` and setting `RELEASE_BRANCH=regular`.

Currently there's only the 'regular' branch though,
and it's the default. So you can ignore this whole page.

(This is inspired by Kubernetes' release channels:
https://cloud.google.com/kubernetes-engine/docs/concepts/release-channels)
